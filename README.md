# my-career-track

An interactive storytelling portfolio by Punit Pritam Mohanty that blends cinematic design, immersive animations, and modern web development to showcase my journey, projects, skills, and creative process.

This site is built with HTML and enhanced with Tailwind CSS, GSAP (ScrollTrigger & Draggable), Lenis for smooth scrolling, Tone.js for cinematic sound design, and a set of modern web fonts.

Live demo

- View the site: https://punitpm.dev

Highlights

- Cinematic, scroll-driven storytelling layout
- Smooth scroll powered by Lenis
- Rich animations and interactions using GSAP (ScrollTrigger, Draggable)
- Minimal, performant HTML-first architecture

How to run locally

1. Clone the repo:

   git clone https://github.com/Punitpritam788/my-career-track.git
2. Open index.html in your browser. (No build step required; site is static HTML/CSS/JS.)
